# Fiscal Astra Documentation

This directory contains implementation and operational documentation for Fiscal Astra.

## Current status

Fase 0 provides the Python application shell, environment configuration, health endpoints,
test runner configuration, and documentation structure. No economic model or numerical
simulation engine is implemented yet.
